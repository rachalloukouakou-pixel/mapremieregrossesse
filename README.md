# Page de vente — Ma première maternité

Site statique (HTML + images), prêt pour Vercel. Aucune installation ni build nécessaire.

## Mettre en ligne
1. Crée un compte sur vercel.com (gratuit).
2. « Add New… » → « Project » → onglet pour déposer un dossier, ou installe Vercel CLI et lance `vercel` dans ce dossier.
3. Framework : « Other ». Laisse vides Build Command et Output Directory.
4. Clique « Deploy ».

## Modifier
- Texte et liens : `index.html` (le lien de paiement apparaît 3 fois : cherche `checkout`).
- Images : dossier `images/` (garde les mêmes noms de fichiers).
